# MemoGen

Army memorandums formatted to AR 25-50, exported as Word or PDF. Open it at https://m94-prog.github.io/memogen/

Everything runs in your browser. Memo text is never saved or sent anywhere: the page's security policy blocks every network
connection. Templates, POCs, signature blocks and letterhead you save stay in that browser only. To move them to another
computer, use Export > Back up saved items, then Export > Restore saved items there.

The public copy starts with a generic letterhead and a set of built-in templates under Start from. Set your letterhead under
Saved > Letterhead, or restore a backup.
